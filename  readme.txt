为 Elementor 页面构建器添加一个 Bilibili 视频小工具，支持设置自动播放、视频尺寸、投影、边框和圆角。

== 描述 ==

**Elementor Bilibili Video** 是一个轻量级插件，为 Elementor 页面构建器添加了一个 Bilibili 视频小工具。通过该插件，你可以轻松地在页面中嵌入 Bilibili 视频，并自定义以下功能：

- **Bilibili 视频 ID**：输入 Bilibili 视频的 BV 号。
- **自动播放**：控制视频是否自动播放。
- **视频尺寸**：设置视频的宽度和高度（支持像素和百分比）。
- **投影**：为视频添加投影效果。
- **边框**：为视频添加边框，并自定义边框样式。
- **圆角**：为视频添加圆角效果。

== 安装 ==

1. 下载插件 ZIP 文件。
2. 进入 WordPress 后台，点击 **插件 > 安装插件 > 上传插件**。
3. 选择下载的 ZIP 文件，点击 **立即安装**。
4. 安装完成后，点击 **启用插件**。

== 使用方法 ==

1. 在 Elementor 编辑器中，将 **Bilibili Video** 小工具拖放到页面中。
2. 输入 Bilibili 视频的 BV 号。
3. 设置是否自动播放。
4. 调整视频的宽度和高度。
5. 在 **样式** 选项卡中，设置投影、边框和圆角。
6. 保存并预览页面。

== 常见问题 ==

= 插件支持哪些版本的 Elementor？ =

插件支持 Elementor 2.0 及以上版本。

= 如何获取 Bilibili 视频的 BV 号？ =

在 Bilibili 视频页面，URL 中的 `BV` 后面的字符串即为视频的 BV 号。例如：
- 视频 URL：`https://www.bilibili.com/video/BV1xx411c7mD`
- BV 号：`BV1xx411c7mD`

= 视频无法播放怎么办？ =

1. 确保输入的 BV 号正确。
2. 检查网络连接是否正常。
3. 如果问题仍然存在，请联系插件开发者。
